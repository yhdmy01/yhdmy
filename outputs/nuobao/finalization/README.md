- `nuobao-final-visual-board.png`：最终视觉锁定候选稿
- `official-board-copy.md`：人工排版文字底稿
- `source-register.csv`：文化资料、参考图和授权状态登记表

视觉版型已锁定。正式提交前需要人工重排所有小字，并逐条核验参考资料的准确来源、链接和授权状态。未核实的信息不得写成确定事实。
